# 简介
本测试用例测试多次上传销售数据是否存在错误

## 数据准备
测试数据目录：`excel/salesRecord/`

### 物料 `material.xlsx`
羊肉（10元/斤）、牛肉（20元/斤）

### 餐品 bom `bom.xlsx`
- 1份红烧羊肉 = 1斤羊肉
- 1份红烧牛肉 = 1斤牛肉
- 1份羊肉炒牛肉 = 0.5斤羊肉 + 0.5斤牛肉

### 销售数据1 `sales1.xlsx`
|菜品名称|销售数量|营业日期|
|-|-|-|
|红烧羊肉|10|2026/07/01|
|红烧牛肉|11|2026/07/01|
|羊肉炒牛肉|12|2026/07/01|

消耗：羊 16、牛 17 → 盘点 100 后库存 **84 / 83**

### 销售数据2 `sales2.xlsx`
|菜品名称|销售数量|营业日期|
|-|-|-|
|红烧羊肉|10|2026/07/01|
|红烧牛肉|12|2026/07/02|
|羊肉炒牛肉|13|2026/07/02|

消耗：羊 16.5、牛 18.5 → 库存 **83.5 / 81.5**

### 销售数据3 `sales3.xlsx`
|菜品名称|销售数量|营业日期|

在已删掉 7/1 的前提下上传：更新/新增 7/2 数据，消耗羊 31.5、牛 33.5 → 库存 **68.5 / 66.5**

### 销售数据4 `sales4.xlsx`
|菜品名称|销售数量|营业日期|

在 sales3（7/2，库存 68.5/66.5）之上新增 7/3：再耗羊 46.5、牛 48.5 → 库存 **22 / 18**

## 测试步骤
1. 上传物料
2. 上传 bom
3. 盘点（2026-06-30），羊肉/牛肉各 100 斤
4. 上传销售记录1 → recal → 验库存与 stockRecord
5. 删除所有 7月1日 销售记录 → recal → 验库存回 100，7/1 的 sales 出库记录为 0
6. 上传销售记录2 → recal → 验库存
7. 再删除所有 7月1日 销售记录 → recal → 验 7/1 的 sales 出库记录为 0
8. 上传销售记录3 → recal → 验库存，且 7/1 的 `stockRecord(type=sales,isDel=0)` 数量为 0
9. 上传销售记录4，然后recal-》验证库存

## 注意点
- 检查库存和 stockRecord 前必须调用 `recal`
- 删销售按日走 `/free/config/delSalesRecord`（测试环境），封装为 `DelSalesByDay`
- 最后 7月1日 的 `stockRecord`：`isDel=0` 且 `type=sales` 的记录数应为 **0**
