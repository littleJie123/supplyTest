# 简介
测试不同分类的物料使用相同编码时，系统是否阻止保存，并提示发生重复的分类和物料名称。

# 测试步骤
1. 引用 `PreTest`：创建餐厅、供应商、肉类和蔬菜分类，并创建肉类物料猪肉，编码为 `MAT001`。
2. 调用 `/app/material/SaveMaterial`，新增蔬菜物料白菜，编码同为 `MAT001`，分类为蔬菜。
3. 预期接口返回错误，错误信息为“肉类的猪肉已经使用该编码”。

# 注意点
- 编码在同一 `warehouseGroupId` 下不能重复，与物料分类无关。
- 错误信息使用已存在的重复编码物料的分类名称和物料名称，而不是当前待保存物料的信息。
