# 简介
测试进销存下载接口 `/app/state/psi`。按物料统计期初/采购/出库/期末的数量、金额、单价；采购口径与入库一致（订单+手工−退货），出库为入库以外类型（报损、盘点，数量金额乘以-1）。数量按物料默认采购单位换算成数字；仅有期初、无期间流水的物料也要出现。7/1 入库压在统计上界上，不得进入 6 月报表。

# 注意点
- **边界条件**：统计区间是 `bussinessDate >= begin 00:00` 且 `< end+1天 00:00`。7/1 手工入库的 `bussinessDate` 恰好等于上限（7/1 00:00:00.000），必须被排除；同时 6/1 订单经 updateNoteTime 后也是 6/1 00:00:00 整点，必须被包含（下限闭区间）
- **采购口径**：订单入库 + 手工入库 − 退货（back 归采购为负）；与 `getInstockType`（instock / handInstock / back）一致
- **出库口径**：入库以外的类型（sales / otherUse / inventory），数量金额乘以 -1 后再汇总。本例无销售；报损为正出库，盘亏为正出库
- **FIFO 计价**：`processSub` 从最旧批次开始扣。报损/退货/盘亏成本都来自批次成本
  - 牛肉退货1包与盘亏1包都落在期初@1元批次 → 采购退货 −100、出库盘亏 100，期末 4包/900
  - 羊肉无期初，报损/退货/盘亏都扣6/1的@2元批次
  - 猪肉报损100g与退货100g都扣期初@1
- **盘点成本由批次重算，输入的 cost 被忽略**（`processSet`，仅库存为空时才用输入成本）：从最新批次往旧回填/清减
- **仅期初物料**：白菜全月无流水，仍出现在表中（期初=期末，采购/出库均为0，采购/出库单价为0）
- **数量不是「几包几克」文本**：接口用 `calCntByUnitsId` 换算成默认采购单位的数字。羊/牛显示包，猪/白菜显示克
- **单价截断不是四舍五入**（`NumUtil.toNum(x, 2)` 用 `Math.floor`）：牛肉采购 800/3=266.666… → `266.66`
- 期末=期初+采购−出库（数量用 `stockDomain.addStocks` / `minus`，金额直接加减）
- 改单据时间一律用 `/app/note/updateNoteTime`，不要用 `/free/update`
- 每个步骤如果需要调用多次接口，请把它集合成 TestCase；只有 1 个 Action 时不要包成 TestCase
- 每个 TestCase 或者 action 都要有备注说明该步骤执行的内容（detail 仅弹窗显示备注）
