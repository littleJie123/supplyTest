## 成本接口

不传 `notInBom`，等于报表的 cost：20962。

`notInBom` 为 `false` 或 `0`，只算销售 BOM 里的物料，塑料杯排除。cost = 20950。这是不含塑料杯时的成本：6500 + 15800 - 650 - 700。

- 期初 0

- 期末 4个 × 2元/个 = 8
- 其他耗用 0
- cost = 0 + 20 - 8 - 0 = 12

- 洋葱按克：每份 100克，10元/斤。卖 4 份。理论数量 400克，理论成本 8元。
