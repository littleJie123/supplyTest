# 注意点
- **边界条件**：统计区间是 `bussinessDate >= begin 00:00` 且 `< end+1天 00:00`。7/1 手工入库的 `bussinessDate` 恰好等于上限（7/1 00:00:00.000），必须被排除；同时 6/1 订单经 updateNoteTime 后也是 6/1 00:00:00 整点，必须被包含（下限闭区间）
- **FIFO 计价**：`processSub` 从最旧批次开始扣。销售/退货/报损/盘亏成本都来自批次成本，与传入的 price 无关（退货 price 会被置0）
  - 牛肉销售70g与退货100g都落在期初@1元批次 → 理论金额70、退货金额100
  - 羊肉无期初，销售/报损/退货都扣6/1的@2元批次；6/30盘亏20g也落在@2 → −40元
  - 猪肉销售140g与报损100g扣期初@1；报损后@1仅剩60g，退货跨批次 60@1+40@2=140元 → 入库金额变为1160；6/30盘亏到80g，清掉@1/@2，只剩最后一批@3的80g → −480g/−980元
- **otherUse（其他消耗）**：计入出库，但不计入实际成本；本例 6/28 报损羊/猪各100g
- **盘点成本由批次重算，输入的 cost 被忽略**（`processSet`，仅库存为空时才用输入成本）：从最新批次往旧回填/清减，每个批次最多到自己的 `maxCnt`，金额按该批次单价折算
  - **盘亏**（羊/猪/牛）：回填不到的最旧部分被清零。羊 200g = [100@2, 100@3]，@2从120清到100 → −20g/−40元，期末 500；**猪 80g = [0@1, 0@2, 80@3]**，从最新@3回填80（max100），更早批次全清 → −480g/−980元，期末 240（验证 FIFO 盘亏只留最后一批）；牛 400g 填满 [300@2, 100@3]，期初@1剩的 30g 被清 → −30g/−30元，期末 900
  - **盘盈超 maxCnt**（竹笋）：只有期初 [100@1(max100)]，盘 120g → 超出 20g 按@1新建批次 → +20g/+20元，期末 120/120
- 入库 = 订单 + 手工入库 − 退货（back 归入库为负）；出库 = 销售 + otherUse + 盘点盈亏（盘盈为负、盘亏为正）
- 理论 = sales 流水；实际 = 出库中排除 otherUse（含盘点盈亏）；白菜/竹笋理论为0 → 差异率按 100%
- **竹笋特殊场景**：全月只有期初盘点和 6/30 盘盈，无销售无入库 → 频次0、理论0、实际=出库=盘盈的负数(−20g/−20元)、期末120 = 期初100 − 出库(−20)
- **差异率是截断不是四舍五入**（`NumUtil.toNum(x, 2)` 用 `Math.floor` 向下取整）：牛肉 30/70=42.857…% → `42.85%`；猪肉数量 480/140=342.857…% → `342.85%`，金额 980/140=700%
- 使用频次 = `count(distinct noteItemId) where type=sales`，销售流水的 noteItemId 是餐品id；猪肉、牛肉频次2，羊肉1，白菜0
- 多物料餐品的销售会按 bom 拆成每个物料一条 sales 流水（猪肉炖粉条1份 → 猪肉20g + 牛肉0.05包 两条流水）
- 改单据时间一律用 `/app/note/updateNoteTime`（订单和退货单都适用），不要用 `/free/update`
- 销售 excel 由 `scripts/genStateExcel.js` 生成到 `excel/state/`；餐品按“菜品名称”匹配已有餐品（先 addProduct 再上传）
- 牛肉标准单位是包（saveBuyUnit 不改 unitsId），bom 用 0.1包/份
- **数量列不是数字**：接口用 `stockDomain.createName` 输出「几包几克」文本。羊/牛整包显示为「2包」「1包」，不足1包显示为「20克」；猪/白菜/竹笋只有克单位
- **物料编码**：建料时通过 SaveMaterial 的 `code` 字段设置（PreTest/AddMaterial 支持 `code` 透传），excel「物料编码」列必须原样下载
- **餐品分析**：行=餐品×物料；消耗来自 sales 流水；用料/金额占比=本行消耗÷该物料全部餐品消耗合计（分母0→0%）；差异=物料实际（出库排除入库与 otherUse，含盘点）×占比−消耗。无销售的物料（白菜/竹笋）不出现；多物料餐品（猪肉炖粉条）拆成多行；物料复用时各餐品占比之和=100%
