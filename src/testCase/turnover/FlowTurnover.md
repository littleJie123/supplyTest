# 简介
测试营业额（turnover）的保存与按月查询。

# 测试步骤
1. 引用 PreTest（初始化餐厅、供应商、物料）
2. 保存 2026-01 营业额：月设定 10000；1日 hand/300；2日 auto/400 且真实营业额 350
3. `listTurnover`（month=`202601`）查询，期望 3 条数据与保存一致
4. 再次保存 1 月：月改为 12000；去掉 1 日；2 日 money 改为 500；新增 3 日 450
5. `listTurnover`（month=`2026-01`）查询，期望剩 3 条（月/2日/3日），1 日已软删
6. 保存 2026-02：月 8000、2月1日 200
7. `listTurnover`（month=`202602`）查询，期望仅 2 月 2 条，不含 1 月数据

# 注意点
- date：月用 `yyyy-MM`，日用 `yyyy-MM-dd`；list 的 month 支持 `202601` / `2026-01`
- 同月再次 save 时，未出现在 array 中的旧日数据会软删（isDel=1）
- 每个 Action 都有 remark；本流程每步仅 1 个接口调用，不包嵌套 TestCase
