# 简介
本用例测试链接单的逻辑正确性。

# 测试步骤

## 创建供应商
创建1个供应商账号，创建3个物料。香蕉（包）、苹果（1包=10斤）、西瓜（1包=1000g）

## 创建 3个门店
创建3门店账号：门店A、门店B、门店C。统一命名为测试门店。（文档中还是以门店A、门店B、门店C命名）。同时在门店新增供应商“测试供应商”。

### 门店A 物料
香蕉（瓶）、苹果（1斤=10袋）、西瓜（1包=1000g）、葡萄（斤）

### 门店B 物料
香蕉（箱）、苹果（1斤=10袋）、西瓜（1包=1000g）、葡萄（公斤）

### 门店c 物料

## 验证
- 主单 `title` 等于主单订单号（`noteId`）
- 链接单 `title` 等于主单订单号
- 供应商订单正确性验证
- 供应商物料正确性验证
- 供应商的门店列表正确性验证

## 订单后续操作
- 发货前先盘点（盘点日为昨天）：按供应商发货明细的订货数量汇总，每个物料再多盘 100。当天盘点在 23:59，会排到发货后面把库存设回去
- 供应商接单、发货、出库
- 发货后按 `materialId` 检查库存：库存 = 盘点初始值 − 发货数量，并且 `stock_record` 有 `type=send` 的负流水。不查 `material` 表（该表没有 `warehouseId`）。
- 查询门店的订单物料，看对应的linkInstockCnt是否正确。
