# 注意点
- 每个步骤如果需要调用多次接口，请把它集合成TestCase；只有 1 个 Action 时不要包成 TestCase。
- 每个TestCase或者action都要有备注说明该步骤执行的内容（detail 仅弹窗显示备注）
- 规格：羊肉标准单位=克（按包 `buyUnitFee=-100`）；牛肉标准单位=包（按包 `buyUnitFee=1`）；猪肉标准单位=克（`buyUnitFee=1`）；西瓜标准单位=个（`buyUnitFee=1`）
- 导入 Excel 在 `excel/flowOtherUse/`。成功文件没有日期、类型；错误文件仍带这两列，用来确认服务端不再校验
- 价格断言用 `StockUtil.isEqPrice`（price + buyUnitFee），数量用 `StockUtil.isEq`
- md「周肉」按「猪肉」；「1包50g」按 1包+50g=150g=1.5包
- 7月1日必须走订单入库流程（createNote/sendNote/processNote），不能用盘点接口
- 修改订单时间用 `/app/note/updateNoteTime`（不要用 `/free/update`）；接口会同步更新 noteItem 流水并重算
