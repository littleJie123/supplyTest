# 简介
测试其他耗用

# 测试步骤
1. 引用PreTestWithMeat
2. 设置5月1日盘点 牛肉1包 羊肉2包 猪肉300g 价格 1元/g
3. 设置6月1日盘点 牛肉2包 羊肉3包 猪肉400g 价格 1元/g
4. 设置7月1日订单入库：createNote → sendNote → processNote；牛肉3包、羊肉4包、猪肉500g，价格 2元/g；再 updateNoteTime 改为7月1日  
   （在6/1盘点基础上**累加**，入库后库存为牛5包/羊7包/猪900g）
5. 检查库存是否正确（牛5/羊7/猪900）
6. 新增7月2日的消耗：牛肉1包、羊肉1包；检查库存（牛4/羊6/猪900）
7. 更改OtherItem：牛肉改为1包+50g=150g(1.5包)，删除羊肉，增加猪肉300g；检查库存（牛3.5/羊7/猪600）
8. 更改OtherUse日期为6月2日；检查库存（6/1盘点−消耗+7/1订单 → 牛3.5/羊7/猪600）
9. 更改OtherUse日期为5月2日；检查库存（消耗被6/1盘点覆盖后再加订单 → 牛5/羊7/猪900）
10. 更改OtherUse日期为7月10日；检查库存（消耗生效 → 牛3.5/羊7/猪600）
11. 删除OtherUse；检查库存（回到订单后水平 → 牛5/羊7/猪900）

# 注意点
- 每个步骤如果需要调用多次接口，请把它集合成TestCase；只有 1 个 Action 时不要包成 TestCase。
- 每个TestCase或者action都要有备注说明该步骤执行的内容（detail 仅弹窗显示备注）
- 规格：羊肉/猪肉标准单位=克（按包 `buyUnitFee=-100`）；牛肉标准单位=包（按包 `buyUnitFee=1`）
- md「周肉」按「猪肉」；「1包50g」按 1包+50g=150g=1.5包
- 7月1日必须走订单入库流程（createNote/sendNote/processNote），不能用盘点接口
- 修改订单时间用 `/app/note/updateNoteTime`（不要用 `/free/update`）；接口会同步更新 noteItem 流水并重算
